# AION Aegis — Identidad visual

## Logo oficial actual

`aion-aegis-logo-dark.svg`

Este asset es la referencia visual oficial para la etapa actual de AION Aegis.

Características:

- fondo negro;
- estructura hexagonal tecnológica;
- órbitas y nodos como lenguaje común AION;
- violeta como inteligencia/energía;
- dorado como jerarquía premium;
- escudo + ADN/vida como símbolo central de Aegis;
- estética futurista sobria, no gamer.

## Regla de composición

Aproximadamente:

- 75% negro/grafito;
- 15% violeta;
- 5% dorado;
- 5% blanco/lavanda.

El dorado no debe convertirse en fondo masivo. Se usa para jerarquía, selección, detalle premium y estados destacados.

## Aplicación UI

El logo puede conservar acabado 3D/glow. La UI cotidiana debe ser más sobria:

- superficies planas oscuras;
- glow controlado;
- bordes discretos;
- iconografía lineal;
- typography legible;
- progressive disclosure;
- no saturar de violeta ni dorado.

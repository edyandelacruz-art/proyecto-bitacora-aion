# AION Memory Architecture

La memoria se almacena independientemente del modelo de IA en una capa estructurada.

## Niveles de Certeza
1. `observed_event`: Evento registrado u observado directamente.
2. `user_informed`: Información dada explícitamente por el usuario.
3. `estimate`: Estimación nutricional o de cantidad basada en evidencia partial.
4. `inference`: Deducción algorítmica o por IA (nunca se asume como hecho sin confirmación).
5. `detected_pattern`: Patrón repetitivo observado en el tiempo.
6. `preference`: Preferencia personal del usuario.
7. `habit`: Hábito recurrente.
8. `user_confirmed`: Dato verificado y confirmado por el usuario.
9. `user_corrected`: Dato corregido manualmente.
10. `recommendation`: Propuesta generada por el agente.

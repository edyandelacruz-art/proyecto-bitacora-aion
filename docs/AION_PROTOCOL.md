# AION Protocol Specification

El **AION Protocol** define el mecanismo de interoperabilidad y comunicación asíncrona entre aplicaciones AION.

## Principales Eventos de Nutrición & Alimentación
- `aion.aegis.nutrition.meal.logged`
- `aion.aegis.nutrition.meal.updated`
- `aion.aegis.nutrition.meal.confirmed`
- `aion.aegis.nutrition.metabolic_state.updated`
- `aion.aegis.nutrition.energy_balance.updated`
- `aion.aegis.nutrition.inventory.updated`
- `aion.aegis.nutrition.food.low`
- `aion.aegis.nutrition.food.expiring`
- `aion.aegis.nutrition.plan.created`
- `aion.aegis.nutrition.plan.updated`
- `aion.aegis.nutrition.recipe.recommended`
- `aion.aegis.nutrition.shopping_list.created`

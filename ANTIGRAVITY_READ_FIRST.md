# ANTIGRAVITY — LEER ANTES DE CONSTRUIR

El documento maestro obligatorio de AION Aegis está en la raíz del repositorio:

**`AION_AEGIS_MASTER_BLUEPRINT.md`**

Lee el archivo completo antes de modificar arquitectura, agentes, módulos, backend, dashboards, exportaciones o UX.

Después:

1. Lee `AGENTS.md`.
2. Audita el código actual y preserva lo que ya es REAL.
3. Crea/actualiza `AION_BUILD_STATUS.md` usando `REAL / PARTIAL / MOCK / PLANNED`.
4. Implementa el Blueprint completo por fases internas sin detenerte a pedir aprobación por decisiones que el Blueprint ya resuelve.
5. Ejecuta build y tests durante la construcción.
6. No inventes datos ni simules éxito.
7. Deja todos los módulos y dashboards navegables para que Edyan los audite posteriormente uno por uno.

La estética oficial inicial es **dark premium: negro/grafito + violeta/lavanda como acento**, con los tokens y reglas definidos en el Blueprint.
